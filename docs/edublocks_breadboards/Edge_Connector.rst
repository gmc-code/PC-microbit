==========================
Edge Connector
==========================

Connecting the microbit
--------------------------

The edge connector lets the microbit plug into the breadboard.

.. image:: images/edge_connector.jpg
    :scale: 100 %

The main pins are:

* pin0
* pin1
* pin2

* 3V (power)
* 0V (ground)

----

The microbit faces upwards.

.. image:: images/main_pins.jpg
    :scale: 50 %
